TECHNICAL TERMS

Reference: the unchanged application source selected before this work.
Candidate: the source with the new test system and test files.
PTY: a pseudo-terminal connected to a real application process.
Case: one named input sequence with explicit expected results.
Checkpoint: an observation after a defined input or state change.
Baseline: a reviewed terminal capture from the reference.
Visual check: an exact comparison against a baseline.
Screen: a route, tab body, overlay, or application phase with distinct output.
State: a meaningful condition of a screen or control.
Fixture: fixed input data supplied by an existing simulation or supported option.
Receipt: a record of source identity, commands, results, and evidence.
Coverage row: one required case in the machine-readable coverage inventory.
Sensitivity probe: a temporary defect used to prove that a test detects that defect.
Retired baseline: a preserved capture with an explicit replacement record.
Technical verbs: spawn, compile, render, capture, assert, commit, rebase, and push.
